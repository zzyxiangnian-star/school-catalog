# school-catalog

Remote marketplace catalog for **school** (Bots, Skills, and MCP Plugins).

## Structure

- `agents.json` — Built-in / curated Bot (Assistant) definitions
- `catalog.json` — Curated Skill index
- `plugins.json` — Curated MCP / Plugin catalog
- `skills/` — Skill bundle archives (`.zip`) and icons (`.icon.svg`)
